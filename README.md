# SaludAppble

SaludAppble is a mobile product-intelligence prototype for scanning food, supplement and cosmetic barcodes and presenting public product data, ingredient context and nutrition information in a clearer interface.

The project uses public data sources including Open Food Facts, Open Beauty Facts and DailyMed. Current evaluation logic is prototype/rule-based; the product does not provide medical advice.
